# fitcheck

An AI wardrobe web app. Before you buy something, it tells you whether the piece suits you, how many things in your closet it pairs with, and whether it closes a gap or creates one.

Built for the Meta Global AI Developer Hackathon (Indie track). Submissions are due 2026-11-04, 9:00 PM ET.

- Features by priority, tech plan and schedule: [docs/SPEC.md](docs/SPEC.md)
- Models: Meta Model API (Muse Spark 1.3, Muse Image, Muse Voice Transcribe, SAM 3.1)
